## 10. Review Notes (Notes for Apple Reviewer)

```
Thank you for reviewing FitQuad.

DEMO LOGIN:
Use the Member credentials above to explore the full member experience (home dashboard, AI coach, workout plan, meal tracking, community feed, leaderboard, marketplace, InBody records, and progress photos).

Use the Coach credentials to see the coach dashboard, member management, session calendar, and the rich coach-member chat with plan sending.

KEY FEATURES TO TEST:
1. Home tab → tap the QR button (top-left) to see the member check-in QR code
2. Train tab → start a workout session (exercises are pre-loaded for the demo account)
3. AI tab → chat with the AI coach (powered by Google Gemini via the app backend — requires internet)
4. Eat tab → tap the barcode icon inside "Log Meal" to test the camera barcode scanner
5. Market tab → browse products; tap any item to see the detail screen
6. Profile tab → Referral code and loyalty points are visible in the profile section

APPLE HEALTH:
The app requests HealthKit access to read steps, heart rate, and sleep, and to write workout data. If running on a device with no Health data, the health section on the home tab will show zeros — this is expected.

CAMERA:
The camera permission is used for the barcode food scanner (Eat tab → Log Meal → barcode icon). It is NOT used for any photo capture other than the progress photo upload which uses the system photo library picker.

PAYMENTS:
In-app payments use Paymob (a regional payment processor). The payment flow opens a secure webview. No actual charges will be made with the demo account — the checkout flow can be entered but the payment webview will show a sandbox/test environment.

PUSH NOTIFICATIONS:
Push notifications require a physical device. On a simulator, the app will silently skip FCM token registration — this is expected and will not cause any errors or crashes.

GEMINI AI:
The AI Coach tab connects to Google Gemini through the app's own backend API. A valid internet connection is required. If the AI response fails, a user-friendly error message is shown in the chat.

If you have any questions, please contact us at support@fitquad.com.
```

## 15. In-App Purchases (if applicable)

The app currently uses **Paymob** for coaching subscription payments and marketplace orders. These are **non-consumable services** billed through the app's own payment flow (webview).

> **Important:** If any digital goods or subscription access is sold *within the app*, Apple requires it to go through **StoreKit / In-App Purchase**. Confirm with your legal/product team whether coaching subscriptions need to be converted to IAP before submission.
